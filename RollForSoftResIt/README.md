# RollFor - SR Provider (softres.it)

Reads [softres.it](https://softres.it) soft-res exports for
[RollFor](https://github.com/rollfor/rollfor)'s SoftRes addon.

## Requirements

`RollFor` and `RollForSoftRes`. Can be installed alongside `RollForRaidRes`.

## Importing

1. Open your raid on softres.it and copy its import string.
2. `/sr` in game, pick **softres.it** in the Provider dropdown, paste the string and click
   **Import**.

## Options

On/off switch on its page in RollFor's options window. Turned off, softres.it leaves the
Provider dropdown after a UI reload; a list already imported stays.
