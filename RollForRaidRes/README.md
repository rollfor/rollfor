# RollFor - SR Provider (raidres.top)

Reads [raidres.top](https://raidres.top) soft-res exports for
[RollFor](https://github.com/rollfor/rollfor)'s SoftRes addon.

## Requirements

`RollFor` and `RollForSoftRes`. Can be installed alongside `RollForSoftResIt`.

## Importing

1. Open your raid on raidres.top and copy its import string.
2. `/sr` in game, pick **raidres.top** in the Provider dropdown, paste the string and click
   **Import**.

## Options

On/off switch on its page in RollFor's options window. Turned off, raidres.top leaves the
Provider dropdown after a UI reload; a list already imported stays.
