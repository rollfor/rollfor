# RollFor - Auto Loot

Master-loots the items you tick straight to yourself when a corpse opens, for
[RollFor](https://github.com/rollfor/rollfor).

## Requirements

`RollFor`.

## Using it

`/rf autoloot` opens the item list. Tick items boss by boss, or a whole quality under
**General**. Hold **Shift** while opening a corpse to loot it yourself instead.

## Settings

On this addon's page in RollFor's options window, and in `/rf config`:

| Setting | Default |
|---|---|
| Auto-loot | on |
| Announce auto-looted items | on |
| Auto-loot messages | off |
